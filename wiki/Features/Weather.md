# Weather

Mina can check weather forecasts for any location using the open-source Open-Meteo API.

## Usage

### Commands
- "Weather in [Location]"
- "What's the weather in [Location]"

### AI Tools
You can ask natural questions about the weather, and Mina will deduce if she needs to check the forecast:
- "Is it raining in Tokyo right now?"
- "Do I need an umbrella for my trip to London?"
- "How cold is it in Toronto?"

## Data Source
Weather data is provided by [Open-Meteo](https://open-meteo.com/).
